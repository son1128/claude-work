# rea-video 검토·실행에서 얻은 교훈

2026-11 기준, 커밋 `356815c`(2026-11-09)를 코드 검토하고 저장소의 데모 영상 두 편(원본 TikTok 실사 광고 `v11_tiktok_original.mp4`, AI 재현판 `v12_oiioii_juicer_remake.mp4`)으로 실행한 결과.

## 1. 보안 검토 요약

| 항목 | 결과 |
|---|---|
| `curl \| bash`, sudo, 셸 설정 수정, cron, 텔레메트리 | 없음 |
| `setup.py` (설치 중 임의 코드) | 없음 — `pyproject.toml` + setuptools만 |
| 모델 다운로드 | GitHub(얼굴 YuNet, UVR MDX-Net 약 67MB), ModelScope(일본어 OCR) — **SHA-256 검증** |
| 외부 AI 전송 | `--vlm`을 켤 때만, 사용자가 설정한 엔드포인트로 프레임 전송. http면 키 평문 경고 |
| `.env` 읽기 | 패키지 루트의 `.env`와 `--env-file`만. 현재 폴더 `.env`는 의도적으로 무시(보안 패치) |
| 저장소의 `SKILL.md` / `AGENTS.md` | 프롬프트 인젝션 없음. 유료 생성 전 dry-run·사용자 동의 요구 |
| 로컬 쓰기 | `~/.cache/rea-video/models`, `~/.rea-video`(선호·교정 기록) |

**공식 `install_skill.sh`의 문제점 (그래서 `scripts/setup.sh`로 대체):**
1. 시스템 Python에 바로 설치될 경우 그 환경의 `opencv-python`을 확인 없이 삭제 → 다른 프로젝트의 `cv2.imshow` 등이 깨질 수 있음.
2. `pip install -e`(편집 모드) + 스킬 심볼릭 링크 → `git pull` 한 번으로 실행 코드와 에이전트 지시문이 무검토로 바뀜.
3. 의존성 상한 없음(Pillow, onnxruntime, PyYAML, rapidocr) → 설치 시점 최신판.

## 2. 설치 시 실측 이슈

- Python 3.13: `rapidocr-onnxruntime>=1.3,<2` 휠 없음 → `[ocr]` 설치 실패. **3.12로 해결.**
- 3.12 venv에서 설치된 버전: numpy 2.5, onnxruntime 1.31, opencv-python-headless 4.14, rapidocr-onnxruntime 1.4.4.

## 3. 정확도 실측

| 영상 | 도구 단독 | Claude 시각 검수 병합 후 | 정답(README) |
|---|---|---|---|
| 원본 광고 (휴대폰 실사, 20.7초, 14컷) | **AI 100% (오판)**, 신뢰도 0.60 | 실사 100%, 신뢰도 0.68 (14컷 전부 정정) | 전부 실사, 한 세트·카메라 위치 2곳 |

- 재현판 재현 계획: "8컷 → 생성 단위 3개(G1 #1–5, G2 #6, G3 #7–8), Seedance 2.5 3회 호출" — README 주장과 일치.
- 도구가 실사를 AI로 본 이유: 재압축으로 센서 노이즈·플랫폼 태그가 사라져 "깨끗한 화면 + AIGC 태그 없음 + 24fps 흔적 없음" 상태 → 기본값이 AI 쪽으로 기움. README도 샘플 재압축 때문에 VLM 없이는 결과가 다를 수 있다고 명시.
- README 공식 수치: 원본 파일 도구 단독 98~99.6%, 위챗 재인코딩 도구 단독 88.6% / Gemini 99.6% / 에이전트 시각 검수 100%.

## 4. 기타 관찰된 한계

- 영어 자막 OCR이 중국어 기본 모델 탓에 깨짐("GAME CHANGER" → 일부만, "Algiond", "Agne" 같은 엉터리). → 자막 문구는 프레임을 보고 보정.
- OCR 언어: zh(중·영)·ja만. **한국어 없음.**
- 보고서 언어: zh·en만. 한국어는 en으로 받고 Claude가 번역·재작성.
- 외부 VLM 없으면: 전체 영상 요약, 등장인물/소품(cast), 컷별 생성 프롬프트가 비어 있음("prompt missing") → 시각 검수에서 채운다.
- 실사 원본의 목소리 유형을 "sung"으로 표시하는 오류가 있었음.
- 효과음 후보 중 `deterministic_anchored` 외 신호 기반 후보는 약 40%만 실제.
- 처리 시간(클라우드 컨테이너): 20초 영상 35~51초.

## 5. 실사 vs AI 판별 단서 (이번 데모에서 실제로 유효했던 것)

**실사였던 원본에서 본 근거**
- 벽시계, 검정·노랑 수납함, 키친타월, 우유통·과자봉지 라벨이 모든 컷에서 위치·디자인 일관, 글자 판독 가능.
- 블렌더 LCD 숫자(45 → 43 → 36)가 깨지지 않음.
- 손등 핏줄·손목시계 자연스러움, 핸드헬드 흔들림, 노출이 컷마다 조금씩 변함.
- 생활감 있는 어수선한 배경(AI는 보통 정돈되고 반복적).

**AI였던 재현판에서 본 근거**
- 배경(시계·나무 벽·대리석)이 원본 세트와 동일 → 원본 프레임을 참조 이미지로 써서 제품만 바꿔 생성.
- 딸기가 프레임 가장자리에서 손 없이 나타나거나 손과의 접촉이 불분명.
- 동작이 느리고 떠다니는 느낌, 조명이 지나치게 균일, 배경 심도 흐림이 일정.
- 제품 로고는 깨지지 않았음 → **로고가 멀쩡하다고 실사라 단정하지 말 것**(최신 모델은 참조 이미지 로고를 잘 유지).

## 6. 이 사용자 작업과의 연결
