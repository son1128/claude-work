# trading-bot-ad-audit: AI 트레이딩 봇 홍보물 정밀 감사

사용자가 보여준 **자동매매·AI 트레이딩 봇 홍보물**을 번역하고, 주장·이미지·유입 경로·기술 내용을 하나씩 뜯어서 **"믿어도 되는가, 무엇을 하면 안 되는가"**를 한국어로 보고한다.

이 스킬은 2026-11에 분석한 실제 사례(페이스북 "Grok AI Trading Bot" 게시물)에서 출발했다. 전체 분석 예시는 `references/case-grok-bot.md`, 위험 신호 체크리스트는 `references/red-flags.md`, 홍보물에 자주 나오는 6-에이전트 매매 파이프라인의 기술 해설은 `references/agent-pipeline.md`.

## 반드시 지킬 원칙

1. **판정은 근거로 한다.** "사기다"라고 단정하지 말고 관찰된 사실(숫자 모순, 0으로 찍힌 카운터, 화면 속 고지문, 유입 구조)을 나열한 뒤 위험도를 매긴다. 특정 개인을 범죄자로 지목하지 않는다 — 게시자 이름·그룹명은 "게시물에 보이는 정보"로만 다룬다.
2. **사용자의 돈·키를 지키는 쪽으로 결론을 낸다.** 시드 문구(복구 구문)·개인 키·거래소 API 키(출금 권한)·원격 접속 앱 설치·"지갑 연결" 요청은 어떤 경우에도 하지 말라고 분명히 쓴다.
3. **외부로 아무것도 보내지 않는다.** 게시자에게 DM·댓글을 대신 보내거나, 링크된 텔레그램 봇·웹사이트·지갑 연결 페이지를 열지 않는다. 링크를 확인해야 하면 주소 문자열만 분석한다(도메인 철자, 단축 URL 여부).
4. **투자 권유를 하지 않는다.** 특정 코인·봇을 사라/팔라고 하지 않는다. 사용자가 비슷한 봇을 직접 만들고 싶어 하면 **페이퍼 트레이딩(모의)·백테스트까지만** 돕고, 실자금 연결은 사용자 본인의 판단·책임임을 밝힌다(`references/agent-pipeline.md` 7절).
5. **번역은 원문을 보존한다.** 이모지·체크박스·대소문자 강조(예: "ANOTHER LEVEL!")·고지문 위치까지 옮겨야 분석에서 근거로 쓸 수 있다.

## 작업 순서

### 1. 전사 (원문 그대로 받아 적기)
- 이미지면 직접 보고 **본문 텍스트 / 이미지 속 UI 텍스트 / 메타데이터**(게시 그룹, 게시자, 경과 시간, 공개 범위, 좋아요·댓글·공유 수, 동영상 여부=재생 버튼)를 분리해서 적는다.
- 작게 흐린 글자(화면 하단 고지문, "illustrative", "paper", "not typical")를 특히 찾는다 — 판정에 결정적인 경우가 많다.
- 읽을 수 없는 부분은 `[판독 불가]`로 표시하고 추측하지 않는다.

### 2. 번역
- 본문은 문단 단위 대역(원문 → 한국어), UI 텍스트는 패널별 표로 정리한다.
- 업계 은어는 괄호로 풀이한다: mcap(시가총액), LP burned(유동성 풀 토큰 소각), mint/freeze revoked(추가 발행·동결 권한 포기), rug(러그풀), bundled launch(번들 출시: 개발자가 여러 지갑으로 첫 블록을 쓸어 담기), trail(추적 손절), paper(모의매매), smart wallets(수익 이력 좋은 지갑) 등.

### 3. 주장 분해
홍보물의 문장을 아래 다섯 종류로 분류해 표로 만든다.

| 종류 | 예 | 확인 방법 |
|---|---|---|
| 수익 주장 | "$44 → $11,643" | 4단계 검산 |
| 기능 주장 | "6개 전문 에이전트", "24/7 자동" | 이미지와 대조, 6단계 |
| 노력 면제 주장 | "차트 안 봐도 됨", "자는 동안" | 리스크 설명 |
| 권위 차용 | "Grok", "ChatGPT", "Claude", 유명인 | 공식 제품 여부 |
| 행동 유도 | "댓글에 GROK", "DM 주세요", "가격은 따로" | 5단계 퍼널 |

### 4. 수익 주장 검산
```bash
python3 -I .claude/skills/trading-bot-ad-audit/scripts/claim_math.py \
  --start <시작금액> --end <주장금액> [--days <기간>] \
  [--position <1회 진입 비중>] [--stop <손절폭>] [--win <승리 1회 평균 수익>] [--fee <왕복 비용>] [--gap <미끄러진 손절>]
```
- 홍보물이 **스스로 밝힌 규칙**(예: "잔고의 최대 8%만 진입", "-6% 손절")을 그대로 넣는다. "자기 규칙대로라면 몇 번을 연속으로 이겨야 하는가"가 가장 설득력 있는 반박이다.
- 기간이 안 적혀 있으면 이미지 속 단서("one night", 타이머)를 쓰고, 없으면 "기간 미기재" 자체를 위험 신호로 기록한다.
- 비용 가정(밈코인 DEX 기준 왕복 1~5%: 수수료 + 슬리피지 + 우선순위 수수료/MEV)과 손절 미끄러짐(갭, 러그 시 -50%~-100%)을 반드시 언급한다.

### 5. 이미지·대시보드 판독
- **본문 숫자와 이미지 숫자가 맞는가?** (예: 본문 $44 vs 화면 시작 잔고 $120)
- **카운터가 0인가?** "0 trades · 0 W · 0 L", "pairs scanned 0" → 실제 거래 기록이 아니라 시연 화면.
- **화면 스스로 밝힌 것:** "paper"(모의), "illustrative"(예시), "not typical", "not financial advice" — 본문 헤드라인과 정면으로 충돌하면 핵심 근거로 쓴다.
- **본문 기능 목록과 화면 구성 요소가 일치하는가?** 이름·개수 불일치는 화면이 다른 곳에서 가져온 것(템플릿·AI 생성 목업)일 가능성을 시사한다.
- 거래 내역 링크(온체인 지갑 주소, 트랜잭션 해시) 같은 **검증 가능한 증거가 있는가?** 없으면 그 자체가 신호.

### 6. 기술 내용 평가
`references/agent-pipeline.md`를 기준으로 화면에 나온 필터·점수·사이징·손절 규칙이 무엇을 해 주고 무엇을 못 해 주는지 쓴다. 핵심 메시지: **러그 필터는 "덜 잃게" 해 줄 수는 있어도 "수익(엣지)"을 만들지는 않는다.** 그리고 LLM 하나("one prompt")가 지갑 키와 실행 인프라 없이 스스로 매매하지는 못한다 — 결국 누군가의 봇/서버에 키나 자금을 넘기는 구조가 된다.

### 7. 유입 퍼널 분석
- 공개 글에서는 가격·실체를 숨기고 **댓글 키워드 → DM**으로 옮기는 구조인가? (댓글 수 > 좋아요 수면 키워드 댓글 유도가 작동했다는 신호)
- DM 이후 흔한 수익화 경로를 `references/red-flags.md` 3절에서 골라 **가능성**으로 제시한다: 봇/강의 판매, 지갑 드레이너(연결·서명 요청), 시드 문구 탈취, 가짜 텔레그램 봇, 추천인/MLM, 펌프 앤 덤프 물량 넘기기, 선입금 후 잠적.

### 8. 위험도 채점과 판정
`references/red-flags.md`의 체크리스트로 해당 항목을 표시하고 점수를 합산해 **낮음 / 주의 / 높음 / 매우 높음** 중 하나로 판정한다. 판정 한 줄 + 근거 3~5개.

### 9. 보고서
아래 구조로 한국어 보고서를 쓴다(대화창에 바로, 길면 사용자가 원할 때 파일로).

1. **한 줄 결론** (판정 + 가장 강한 근거 하나)
2. **번역** (본문 대역 + 이미지 UI 표)
3. **주장 vs 사실** 표
4. **수익 검산** (스크립트 출력 요약)
5. **이미지 판독** (모순·0 카운터·고지문)
6. **기술 해설** (무엇이 진짜 기법이고 무엇이 과장인가)
7. **퍼널과 예상 수익화 경로**
8. **위험 신호 점수표**
9. **사용자 행동 지침** — 하지 말 것 / 이미 했다면 할 것 / 신고처(`references/red-flags.md` 5절)
10. **배울 점** — 이 홍보물에서 정당하게 가져갈 수 있는 지식(필터 설계, 리스크 관리 개념 등)

## 자주 하는 실수

- 헤드라인 숫자만 반박하고 **화면 속 고지문**을 놓친다 → 홍보물이 스스로 "예시/모의"라고 적어 둔 경우가 많다. 이것이 제일 강한 근거다.
- 필터 규칙이 그럴듯하다는 이유로 "기술적으로는 진짜"라고 결론 낸다 → 규칙은 공개된 상식(러그 체크 체크리스트)이며, 수익을 보장하지 않는다.
- 하단 "Trading involves risk" 고지를 면책으로 받아들인다 → 헤드라인이 과장 수익을 약속하는 한 고지문은 법적 방패일 뿐 정보가 아니다.
- 게시자 개인을 공격하거나 신상을 추적한다 → 하지 않는다. 구조와 위험만 다룬다.
