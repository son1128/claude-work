## 2. 흔한 화면 연출 기법

- **목업 대시보드:** 터미널 감성(모노스페이스, 네온, macOS 창 버튼) + 에이전트 카드 + 흐름도. 생성형 AI로 HTML 한 장을 만들어 녹화하면 몇 분이면 나온다. 숫자가 0이거나, 토큰 이름이 가상($SOLLY, $DRIFTO 등)이거나, 시간이 정확히 23:00:00 같은 정각이면 시연용.
- **잔고 스크린샷:** 거래소 앱 화면은 웹 개발자도구로 숫자만 바꿔 쉽게 위조된다. 원본 체결 내역·온체인 기록이 아니면 증거로 치지 않는다.
- **"paper ✓ → live" 토글:** 모의매매를 통과했다는 연출. 모의 성과는 슬리피지·MEV·유동성 부족이 없어 실제보다 항상 좋다.

## 3. DM 이후 흔한 수익화 경로 (가능성으로만 제시)

1. **봇·강의·"셋업 가이드" 판매** — 돈은 판매에서 나오고 봇 성과는 무관.
2. **지갑 드레이너** — "봇 연결"이라며 dApp에 지갑 연결 → 무제한 승인 서명 → 자산 인출.
3. **시드 문구·개인 키 탈취** — "봇이 매매하려면 키가 필요" → 지갑 전체 탈취.
4. **가짜/악성 텔레그램 트레이딩 봇** — 봇이 생성한 지갑의 키를 운영자가 보관.
5. **선입금 후 잠적 / 출금 수수료 요구** — 대시보드상 수익이 불어나지만 출금 불가.
6. **펌프 앤 덤프** — 구매자들에게 특정 밈코인을 사게 해 운영자 물량을 넘김.
7. **추천인 피라미드** — 신규 가입비로 기존 회원 "수익"을 지급.

## 4. 이미 했다면 (사용자 행동 지침)

- 시드 문구·개인 키를 입력/전송했다 → **그 지갑은 이미 털린 것으로 간주**. 새 지갑(새 시드)을 만들고 남은 자산을 즉시 옮긴다.
- 지갑을 연결·서명했다 → 토큰 승인 해제 도구(예: 각 체인의 공식 블록 탐색기 승인 관리 메뉴)로 승인 취소, 자산 이동.
- 거래소 API 키를 줬다 → 즉시 키 삭제, 비밀번호·2단계 인증 재설정, 출금 주소 화이트리스트 확인.
- 원격 접속 앱을 설치했다 → 앱 삭제, 기기 점검, 금융 앱 비밀번호 변경.
- 돈을 보냈다 → 송금 내역·대화 캡처 보존 후 아래 신고처에 신고. "복구해 주겠다"는 2차 연락(리커버리 사기)은 무시.
