## 핵심 발견

1. **헤드라인과 화면이 서로 다른 이야기를 한다.** 본문은 $44 → $11,643, 화면은 시작 $120에 거래 0건·승패 0. $11,643이라는 숫자는 이미지 어디에도 없다.
2. **화면이 스스로 시연용이라고 밝힌다.** `trade detail illustrative`, `paper run first`, `one result · not typical`. 모든 카운터가 0이고 시간이 정각 23:00:00 — 실제 운용 기록이 아니라 연출된 목업(생성형 AI로 만든 HTML 대시보드 녹화로 보임).
3. **기능 목록이 화면과 다르다.** 본문 6개(스캐너·리스크체커·포지션사이저·실행기·로거·성과추적기) vs 화면 6개(SCOUT·FILTER·ANALYST·EXECUTOR·RISK·LOGGER). 채점 엔진(ANALYST)과 손절(RISK)은 본문에 없고, 성과추적기는 화면에 없다 → 화면을 다른 곳에서 가져왔거나 설명을 대충 붙였을 가능성.
4. **자기 규칙으로는 불가능한 수익.** 264.6배(+26,361%). 잔고 8% 진입·승리당 +100%·비용 2%면 손실 없이 **74번 연속** 승리 필요. 승률 50%라도 평균 약 162회 거래 필요. 하룻밤(약 8시간) × 2.4페어/분 ≈ 1,150페어 → 91% 탈락 후 약 100개 → 70점 통과는 그보다 훨씬 적음. 승리당 +30%면 연속 252승.
5. **"Grok" 이름 차용.** xAI의 Grok은 대화형 AI이며 공식 "Grok 트레이딩 봇" 제품이 아니다. "My Grok AI Trading Bot"은 개인이 이름을 빌린 것. "프롬프트 하나 붙여 넣고 잤다"는 LLM이 지갑 키·실행 서버 없이 매매할 수 있다는 오해를 노린다.
6. **가격 비공개 + 댓글 키워드 + DM.** 공개 장소에서는 검증·비교를 피하고, 1:1 채널에서 판매·결제·"설정"을 진행하는 구조. 설정 과정에서 지갑 키·연결 서명을 요구하면 자산 탈취로 이어질 수 있다.
7. **필터 규칙은 진짜 지식이다 — 단, 방어용.** 8개 하드 룰은 밈코인 러그 체크의 공개 상식이며 손실 확률을 줄일 뿐 수익을 만들지 않는다. -6% 손절은 DEX에서 보장되지 않는다(갭·러그·허니팟).
