# FusionMain — 메인 차트 지표 융합

TradingView용 Pine Script v6 지표입니다. 차트에 따로 올려 쓰던 메인 차트 지표 7종을 한 스크립트로 합쳤습니다. 각 지표의 방향을 점수로 더해 **융합 점수(−8 ~ +8)** 로 현재 우위를 판정합니다.

- 코드: [`fusion-main.pine`](fusion-main.pine)

> ⚠️ 원본 지표(LuxAlgo Order Block Detector, Nephew_Sam FVG, ChartPrime SR, GridBotDir 등)의 코드를 복사한 것이 아닙니다. 화면에 보이는 설정값과 각 지표의 개념을 바탕으로 새로 구현했기 때문에 값이 원본과 조금 다를 수 있습니다. 투자 판단은 본인 책임입니다.

## 구성 요소와 점수

| # | 구성 요소 | 기본 설정 | 점수 규칙 |
|---|---|---|---|
| ① | EMA | 240 | 종가가 EMA 위면 +1, 아래면 −1 |
| ② | 이치모쿠 | 3 / 13 / 26 / 1 | 구름 위 +1, 구름 아래 −1, 구름 안 0 |
| ② | 전환선 vs 기준선 | — | 전환선이 위면 +1, 아래면 −1 |
| ③ | 오더블록 | 거래량 피벗 5, 상승·하락 각 3개, Wick | 하락 OB 안이면 −1, 상승 OB 안이면 +1, 그 밖에는 가장 최근 OB 방향 |
| ④ | 그리드 | 100봉, 10칸 | 중간선 위 + EMA 상승이면 LONG(+1), 중간선 아래 + EMA 하락이면 SHORT(−1), 그 밖에는 NEUTRAL(0) |
| ⑤ | 지지/저항 | 피벗 8, 각 6개 | 가장 최근에 저항을 돌파했으면 +1, 지지를 이탈했으면 −1 |
| ⑥ | FVG | 15m · 1H · 4H · D | 가장 최근에 생긴 FVG 방향 ±1 (상위 TF 우선) |
| ⑦ | 거래량 | MA 10, 급증 2배 | 평균 이상 거래량의 양봉이면 +1, 음봉이면 −1 |

신호 임계값의 기본값은 4입니다. 점수가 **+4 이상으로 올라서는 봉에 `L`**, **−4 이하로 내려서는 봉에 `S`** 라벨이 붙습니다.

## 차트에 추가하기

1. TradingView 아래쪽 **Pine 편집기**를 엽니다.
2. **새로 만들기 → 인디케이터**를 고르고 기본 코드를 지웁니다.
3. [`fusion-main.pine`](fusion-main.pine) 전체를 붙여넣고 **저장** → **차트에 추가**를 누릅니다.
4. 같은 역할의 기존 지표(EMA 240, 이치모쿠, Order Block Detector, GridBotDir, SR, FVG)는 숨기거나 삭제하세요. 겹쳐 그려집니다.

## 렌코 차트에서 쓸 때

- 상위 TF FVG는 `ticker.standard()`로 **일반 캔들 데이터**를 가져와 계산합니다. 렌코 벽돌과 상관없이 실제 15분/1시간/4시간/일봉 갭이 표시됩니다.
- **현재 차트 FVG**는 기본값이 꺼져 있습니다. 렌코는 같은 방향 벽돌 3개가 이어지면 매번 갭이 생겨 박스가 과하게 그려지기 때문입니다.
- 상위 TF FVG는 마감된 봉 기준(`[1]` + `lookahead_on`)이라 리페인트되지 않습니다.

## 대시보드 (오른쪽 위)

| 행 | 내용 |
|---|---|
| EMA 240 | EMA 값과 판정 |
| 구름 | 현재 봉 위치의 구름 하단 ~ 상단 |
| 전환 / 기준 | 이치모쿠 전환선 / 기준선 |
| OB 저항 / 지지 | 위쪽 가장 가까운 하락 OB 하단 / 아래쪽 가장 가까운 상승 OB 상단 |
| 그리드 | 방향(LONG·SHORT·NEUTRAL), 범위, 범위 안에서의 위치(%) |
| S/R 저항 / 지지 | 가장 가까운 피벗 저항 / 지지 |
| FVG 위 / 아래 | 아직 메워지지 않은 가장 가까운 하락 FVG / 상승 FVG |
| 거래량 / MA10 | 평균 대비 배수 |
| 융합 점수 | 합계와 판정 (강한 매수 우위 / 매수 우위 / 중립 / 매도 우위 / 강한 매도 우위) |

## 알림

알림 창의 조건에서 `FusionMain`을 고른 뒤 다음 중 하나를 선택합니다. 트리거는 **봉 마감 시 한 번**을 권장합니다.

- 융합 매수 신호 / 융합 매도 신호
- EMA 상향 돌파 / EMA 하향 이탈
- 저항 돌파 / 지지 이탈
- 구름 상향 돌파 / 구름 하향 이탈
