PPP 지표 해부 보고서

「직장인도 쉽게 사용 가능한 PPP지표 사용법」(핑퐁팽, 11쪽)을 그림까지 분석하고, 지표를 Pine Script로 재현해 바이낸스 1분봉 55일치로 문서의 매매 규칙을 검증했습니다.

결론. 교본으로서 규칙 정리는 깔끔합니다. 지표는 스토캐스틱 RSI 계열을 다시 포장한 것으로 보입니다. 문서의 4P 규칙을 그대로 자동화하면 수수료 전에도 손익비 0.86으로 손실이었고, 승률은 41%였습니다. 광고의 "승률 90%"는 재현되지 않았습니다.

이 페이지는 투자 조언이 아닙니다. 원본 PPP 지표는 비공개라서 계산식은 문서 내용으로 추정했습니다.

02PPP 지표의 정체

문서 2쪽이 밝힌 제작 과정은 이렇습니다.

추세 방향→상대강도 RSI→추세 필터링 EMA→모멘텀 가속도 = PPP

그림에서 보이는 특징은 0~100 범위의 두 선(K, D), 25·50·75 기준선, 두 선 사이 띠의 네 가지 색입니다. 곡선이 바닥과 천장에 오래 머무는 모양은 전형적인 Stochastic RSI와 같습니다. 띠 색은 두 선의 간격이 커지는지 줄어드는지로 칠하는 방식이며, TradingView에 흔한 4색 MACD 히스토그램과 같은 논리입니다.

띠 색조건 (재현식)문서의 대응
강세 확장 (적갈색)K ≥ D, |K−D| 커짐롱 유지, 익절 서두르지 않음
강세 유지·둔화 (연분홍)K ≥ D, |K−D| 작아짐익절 준비, 신규 진입 신중
약세 확장 (올리브)K < D, |K−D| 커짐숏 유지, 롱 금지
약세 유지·둔화 (연노랑)K < D, |K−D| 작아짐숏 익절 준비, 반등 경계

원본은 초대 전용 스크립트라 계산식과 설정값이 공개되지 않았습니다. 재현식은 RSI(14) → 스토캐스틱(14) → EMA(3) = K → EMA(3) = D입니다.

034P 매매 체계

단계문서 내용실제로 쓰는 도구
1P 방향1시간봉 장기 이평 정배열/역배열이동평균
2P 자리1분봉 장기 이평(60·120·240) 터치이동평균
3P 신호PPP 골든/데드 크로스, 위치(25 이하/75 이상), 막 난 크로스인지PPP 지표
확정봉 마감 후 진입, 예측 진입 금지원칙
4P 중첩다이버전스·패턴·거래량 중 하나 이상보조 근거
익절다음 이평 자리, 볼린저밴드 상단·20이평·전고점, 반대 크로스 중 먼저이평·볼밴·PPP
손절현재 장기 이평 이탈(롱)·돌파(숏)이동평균

방향, 자리, 익절, 손절이 모두 이동평균으로 정해집니다. PPP 지표는 "언제 들어가느냐"만 맡습니다. 문서도 "자리(2P)가 없는 크로스는 노이즈"라고 반복합니다.

잘 만든 부분

  • 봉 마감 확정 원칙은 봉 진행 중 신호가 바뀌는 문제를 막습니다.
  • "늦게 탄 골크는 남들 익절 물량 받아주는 자리"는 추격 매수를 막는 좋은 규칙입니다.
  • 손절 기준을 지표가 아니라 가격 구조(이평)에 둡니다.
  • "지표가 애매하면 진입하지 않는다"는 매매 횟수를 줄이는 필터입니다.

04그림별 분석

쪽그림관찰
1표지 일러스트캔들·거래량·오실레이터를 합친 장식 이미지입니다. 실제 데이터가 아닙니다.
3오실레이터 확대 화면①교차 ②위치 ③이격을 화살표로 표시했습니다. 오른쪽 축이 −90~180으로 넓지만 값은 0~95에서만 움직입니다. 본문은 "흰 선과 분홍 선"이라고 하는데 화면에서는 둘 다 분홍 계열로 보입니다. 2026년 6월 캡처입니다.
4골크=롱, 데크=숏골크(아래 점선 근처) 뒤 상승, 데크(위 점선 근처) 뒤 하락. 결과가 가장 깔끔한 구간을 고른 예시입니다.
5띠 색 화면상승 초반 적갈색 → 꼭대기 근처 연분홍, 하락 초반 올리브 → 바닥 근처 연노랑. 색은 선이 꺾이기 직전이나 직후에 바뀌어서 선행 신호라기보다 동행 신호에 가깝습니다.
6과매수·과매도문서 안의 모순. 위쪽 데드크로스 뒤에도 가격이 계속 올라 신고가를 냅니다. "과매수 = 롱 힘 최강"은 뒷받침하지만 같은 쪽 표의 "75 이상 데드크로스 → 숏" 규칙은 이 차트에서 실패합니다.
7A 막 골크 / B 늦은 골크실제 차트가 아니라 그래픽 개념도입니다. "몇 봉 전까지가 '막'인지" 숫자 기준이 없습니다.
8번호 표식 차트가운데 "리플레이" 워터마크가 있습니다. TradingView 바 리플레이로 과거를 재생하며 붙인 표식이라 실시간 성과의 증거가 되지 못합니다.
9익절 예시가격대 약 0.2, 1분봉으로 보아 알트코인 USDT 무기한 선물로 추정됩니다. 해상도가 낮습니다.
11손익 달력, 자산 화면6월 손익 +9,866.41, 5/07~7/17 Total PnL 20,407.2 USDT. 달력에 손실일이 보입니다(11일 −36.74, 18일 −164.21, 26일 −66.78).

05광고 주장 점검

주장문제
"62전 62승" + "승률 90%"100%와 90%가 한 화면에 함께 있고 기간 설명이 없습니다.
"손절 없이 기록"달력에 손실일이 있습니다. 손절하지 않는 매매는 승률이 높아 보여도 한 번에 크게 잃는 구조입니다. 문서 9~10쪽의 손절 규칙과도 맞지 않습니다.
"월 수익률 380%", "100불 진입"9,866 ÷ 3.8 ≈ 2,600달러라 원금이 약 2,600달러였다는 계산이 됩니다. 100달러 진입으로 그만큼 벌려면 높은 레버리지가 필요합니다. 원금, 최대 낙폭, 수수료, 펀딩비는 공개되지 않았습니다.
"월 1,300만 원"72일 합계 20,407 USDT 중 가장 좋았던 6월 기준으로 보입니다.
"나머지는 제가 다 책임지겠습니다"손실 보전이나 수익 보장으로 읽힐 수 있습니다. 국내 자본시장법은 유사투자자문업자의 손실보전·이익보장 약속을 금지합니다.
"하루 30분", "10초 만에", "제2의 월급"1분봉 선물 스캘핑의 실제 부담을 가리는 표현입니다. 이번 검증에서 규칙대로라면 종목당 하루 40회 안팎 거래가 나왔습니다.

06Pine Script 구현

두 파일 모두 TradingView Pine Script v6입니다. Pine 편집기 → 새로 만들기 → 전체 붙여넣기 → 저장 → 차트에 추가 순서로 씁니다.

  • 지표: K/D 두 선, 띠 색 4가지, 25·50·75 기준선, 크로스 원(강한 크로스는 큰 원), 가격 차트 위 4P 진입 신호(L/S), 알림 4종.
  • 전략: 같은 계산에 문서의 진입·익절·손절 규칙을 넣은 백테스트용. 기본 수수료는 편도 0.05%입니다.
문서 규칙코드로 옮긴 방식
1P 방향직전 확정 1시간봉 EMA 60 > 120 > 240이면 롱만, 반대면 숏만 ([1] + lookahead_on으로 미래 값 참조 방지)
2P 자리최근 5봉 안에 봉 범위가 EMA에 닿았고 종가가 그 EMA 위(롱)/아래(숏)
3P 신호교차한 그 봉. 25 이하/75 이상은 강한 크로스, 25~75는 2P와 겹칠 때만
확정barstate.isconfirmed, 전략은 process_orders_on_close
익절볼린저밴드(20, 2) 지정가, 또는 반대 크로스 시 종가 청산
손절진입 근거 EMA를 종가가 0.05% 넘게 벗어나면 종가 청산
4P 중첩판단 기준이 문서에 없어 넣지 않았습니다.
ppp-oscillator.pine (지표) 
// This Pine Script™ code is subject to the terms of the Mozilla Public License 2.0 at https://mozilla.org/MPL/2.0/
//
// PPP 재현 오실레이터 (PPP Clone)
// ─────────────────────────────────────────────────────────────────────────────
// 「PPP 지표 사용 가이드」(핑퐁팽) 문서의 그림과 설명만 보고 만든 "재현본"입니다.
// 원본 PPP 지표는 비공개(초대 전용) 스크립트라서 계산식·설정값이 공개되지 않았고,
// 이 코드는 원본과 같다는 보장이 없습니다.
//
// 문서가 밝힌 구성: 추세 방향 → 상대강도(RSI) → 추세 필터링(EMA) → 모멘텀 가속도
//   1) RSI(14)                      상대강도
//   2) RSI의 스토캐스틱(14)          0~100 범위로 정규화 (그림의 0~95 왕복 모양)
//   3) EMA(3) 스무딩 → K(흰 선)      노이즈 제거
//   4) K의 EMA(3) → D(분홍 선)       Signal
//   5) |K − D| 증감 → 띠 색 4가지     모멘텀 가속·감속
//
// 화면에서 읽는 세 가지 (문서 3쪽)
//   방향   — 흰 선(K)이 분홍 선(D) 위인가 아래인가 / 교차가 곧 트리거
//   강도   — 교차 위치: 과매도 25 이하 골든크로스, 과매수 75 이상 데드크로스가 강함
//   변화율 — 두 선 이격이 벌어지는지(확장) 좁아지는지(둔화) → 띠 색
//
// 4P 필터 (문서 8·10쪽, 기본 켜짐) — 가격 차트 위에 진입 신호를 표시합니다.
//   1P 방향: 상위 시간봉(기본 1시간) EMA 60·120·240 정배열이면 롱만, 역배열이면 숏만
//   2P 자리: 최근 N봉 안에 현재 차트의 EMA 60·120·240 중 하나에 닿았는가
//   3P 신호: PPP 크로스가 "막" 났는가 (교차 직후 봉)
//   확정   : 봉 마감 후에만 신호 확정 (알림도 봉 마감 기준)
//
// 사용법: TradingView → Pine 편집기 → 새로 만들기 → 인디케이터 → 이 코드 전체 붙여넣기 →
//        저장 → "차트에 추가". 문서 권장 세팅은 1분봉 차트입니다.
//@version=6
indicator("PPP 재현 오실레이터 (PPP Clone)", shorttitle = "PPP≈", overlay = false, precision = 2)

grpView  = "표시"

// ─── 오실레이터 ───────────────────────────────────────────────────────────────

rsi   = ta.rsi(close, rsiLen)
hh    = ta.highest(rsi, stochLen)

var float stochRsi = na
stochRsi := hh - ll > 0 ? 100 * (rsi - ll) / (hh - ll) : nz(stochRsi[1], 50)

dc       = ta.crossunder(k, d)

dcStrong = dc and crossLvl >= obLvl
