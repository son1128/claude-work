# 쇼핑 쇼츠 이중 수익화 플레이북

분석 대상: 마브스쿨 「[10/21 원데이 라이브] 퍼온 영상 만으로 월 2000 번 이중 수익화 노하우」 랜딩 페이지 (sellall.dbcart.net, 2026-10-18 확인).
실행 도구: [`mini-apps/dual-shorts/index.html`](../mini-apps/dual-shorts/index.html)

> 이 문서는 무료특강 **광고 페이지**에 공개된 내용만으로 구조를 재구성한 것입니다. 실제 유료 강의 내용은 포함되어 있지 않으며, 페이지의 수익 수치는 운영자의 주장으로 검증되지 않았습니다.

## 1. 페이지가 공개한 공식

| 요소 | 내용 |
|---|---|
| 콘텐츠 | 15초 쇼핑 쇼츠, 촬영·얼굴 노출 없음, "해외에서 이미 완성된 숏폼을 가져와서 사용" |
| 1단계 수익 | 쿠팡 파트너스 링크 수수료 (약 3%) — 구독자 0명이어도 첫 영상부터 |
| 2단계 수익 | 같은 영상으로 물건을 직접 판매, 판매 마진 35~65% 정산 (운영자 벤더사 상품 판매 구조로 추정) |
| 확장 | 영상 1개를 인스타·유튜브·틱톡 3채널에 배포 |
| 루틴 | 퇴근 후 하루 2시간 |
| 주장 수익 | 월 순수익 2,100만 원 = 쿠팡 수수료 1,000만 원 + 물건 판매 1,100만 원 |

## 2. 숫자로 다시 보기

`dual-shorts`의 목표 역산 기본값(수수료 3%, 평균 주문 3만 원·전환 10%, 직접 판매 마진 40%·평균 주문 2.5만 원·전환 3%, 조회→클릭 1%, 월 60편 × 3채널)으로 계산하면:

| 항목 | 필요량 |
|---|---|
| 제휴 매출 (1,000만 원 ÷ 3%) | 약 3억 3,333만 원 / 주문 약 11,112건 |
| 직접 판매 매출 (1,100만 원 ÷ 40%) | 2,750만 원 / 주문 1,100건 |
| 링크 클릭 | 약 14만 8천 회 |
| 월 조회수 | 약 1,478만 회 |
| 업로드 1건당 평균 조회수 | 약 8만 2천 회 |

수수료만으로 1,000만 원을 벌려면 매출 3억이 필요하므로, **실질적인 돈은 2단계(직접 판매 마진)에서 나옵니다.** 1단계는 어떤 상품이 팔리는지 무료로 검증하는 단계로 보는 것이 맞습니다.

## 3. 그대로 따라 하면 안 되는 부분

- **퍼온 영상**: 원작자 허락 없는 재업로드는 저작권 침해이며, 유튜브는 재사용 콘텐츠를 수익 창출 대상에서 제외합니다. → 직접 촬영, 제조사·판매사 허락, 무료 사용 허용 소재 + 내 해설만 사용.
- **광고 표시**: 제휴 링크와 직접 판매 영상에는 경제적 이해관계 표시가 필요합니다(공정위 추천·보증 심사지침). 쿠팡 파트너스 문구: "이 게시물은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- **직접 판매 요건**: 사업자등록, 통신판매업 신고, 품목별 KC 인증 확인.
- **수익 인증**: 잘된 사례만 고른 것(생존자 편향)이며 매출·순수익 구분이 불분명합니다.

## 4. 실행 시스템 (dual-shorts 앱)

| 탭 | 하는 일 |
|---|---|
| ① 공식 | 이중 수익 구조 요약 + 매일 초기화되는 2시간 루틴 체크리스트 |
| ② 목표 역산 | 목표 수익 → 필요한 매출·주문·클릭·조회수·업로드당 조회수, 현실 점검 경고 |
| ③ 상품·마진 | 제휴/위탁/사입/자체 상품 등록, 건당 순이익·마진 자동 계산, 20% 미만 경고 |
| ④ 15초 대본 | 훅 3종 × 상품 정보로 대본 + 유튜브·인스타·틱톡 캡션 생성, 광고 표시 자동 삽입, 출처 불명 영상은 생성 거부 |
| ⑤ 성과 기록 | 업로드별 조회·클릭·주문 기록, 수익 자동 계산 |
| ⑥ 대시보드 | 월별 제휴/직접 판매 수익, 목표 달성률, 채널·상품별 성과, 다음 행동 제안 |

데이터는 브라우저 localStorage에만 저장되며 JSON 백업 저장·불러오기를 지원합니다.

## 5. 단계별 운영 순서

1. **1~4주차 — 검증**: 제휴 상품 3~5개 등록 → 하루 2편 × 3채널 업로드 → 매일 기록. 목표: 첫 수익, 클릭률 높은 카테고리 1~2개.
2. **5~10주차 — 마진 전환**: 제휴로 5건 이상 팔린 상품을 위탁 → 소량 사입으로 직접 판매. 순마진 20% 미만은 중단.
3. **7~12주차 — 채널 정리**: 채널별 클릭률·전환율 비교, 낮은 채널은 첫 자막·링크 안내 문구 A/B 테스트.
4. **13주차~ — 확장**: 실제 성과가 3개월 이상 쌓인 뒤에만 교육·대행 사업 검토.

목표는 한 번에 2,000만 원이 아니라 **월 100만 → 500만 → 2,000만 원**처럼 단계별로 올리고, 각 단계에서 ② 목표 역산의 "업로드 1건당 조회수"가 내 채널 평균의 2배 이내인지 확인합니다.
